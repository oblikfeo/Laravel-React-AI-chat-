# Дизайн-система Uncensia

Единый свод правил оформления. На него опираемся при отрисовке **всех** новых страниц, чтобы интерфейс оставался цельным.

Источник истины — макеты в `figma/`:
- `1440w dark.jpg` — десктоп, сайдбар свёрнут
- `1440w dark-2.jpg` — десктоп, сайдбар развёрнут
- `Arcana mobile homepage.png` — мобильное меню
- `1.png` — мобильная главная
- `fon.png` — фоновое изображение (лежит в `server/public/images/space-bg.png`)

---

## 1. Фон

Фон — **фотография космоса с планетой снизу**, а не градиент.

```
background-image: url('/images/space-bg.png')
background-size: cover
background-position: center bottom
```

Фон фиксирован (`fixed inset-0 -z-10`), контент скроллится поверх. Планета всегда внизу экрана, свечение по центру-низу.

В светлой теме поверх фона кладётся светлая вуаль (см. раздел «Темы»).

## 2. Цвета

### Базовые

| Токен | Значение | Где применяется |
|---|---|---|
| Фон сайдбара | `#0a0a0f` c `backdrop-blur` | Боковое меню |
| Текст основной | `#ffffff` | Заголовки, активные пункты |
| Текст вторичный | `rgba(255,255,255,0.65)` | Пункты меню, подписи |
| Текст приглушённый | `rgba(255,255,255,0.45)` | Плейсхолдеры, мелкие подписи |
| Граница | `rgba(255,255,255,0.10)` | Рамки карточек, кнопок, инпута |
| Поверхность | `rgba(255,255,255,0.05)` | Стеклянные плашки |
| Поверхность-ховер | `rgba(255,255,255,0.10)` | Наведение |

### Акцентные

| Токен | Значение | Где применяется |
|---|---|---|
| Кнопка New chat | градиент `#dff3ff → #eaf6ff` | Главная кнопка в сайдбаре |
| Логотип | градиент фиолетовый → голубой (`#a78bfa → #7dd3fc`) | Значок «b» |
| Кнопка отправки | `#ffffff` фон, чёрная стрелка | Отправка промпта |
| Индикатор онлайн | `#22c55e` | Точка у аватара |

Специальных цветов ошибок/успеха макет не задаёт: используем стандартные `red-400` и `green-400` в том же стеклянном стиле.

## 3. Типографика

Шрифт интерфейса — гротеск (в проекте Figtree, подключён в Breeze).

| Элемент | Размер | Начертание |
|---|---|---|
| Логотип «uncensia» по центру | 72–96px, десктоп `text-8xl` | Light (300), межбуквенное чуть сжатое |
| Логотип в сайдбаре | 20px | Regular |
| Слоган | 18px | Regular, вторичный цвет |
| Пункт меню | 15px | Regular; активный — Medium |
| Текст в поле ввода | 17px | Regular |
| Быстрые действия (pill) | 14px | Regular |
| Подпись под именем юзера | 12px | Regular, приглушённый |

Начертание логотипа в макете — тонкое и широкое. Добиваемся через `font-light` и `tracking-tight`.

## 5. Эффект стекла

Ключевой приём макета. Все поверхности поверх фона — полупрозрачные с размытием.

```
bg-white/5  border border-white/10  backdrop-blur-xl
```

Поле ввода промпта размыто сильнее остальных элементов и имеет заметную тень: `shadow-2xl shadow-black/40`.

| Параметр | Значение |
|---|---|
| Сайдбар свёрнутый | 72px |
| Сайдбар развёрнутый | 280px |

Центральный блок выровнен по вертикали примерно на 45% высоты экрана, а не строго по центру: под полем ввода остаётся воздух для быстрых действий.

## 7. Состояния элементов

- **Покой**: прозрачный фон, вторичный текст.
- **Наведение**: фон `white/10`, текст белый, переход `transition` 150мс.
- **Активный пункт меню**: фон `white/10`, текст белый, начертание Medium.
- **Кнопка отправки неактивна**: непрозрачность 40%, курсор обычный.
- **Фокус**: обводка не рисуется поверх стекла, вместо неё чуть светлее рамка.

---

## 8. Темы

Переключатель в правом верхнем углу: капсула с двумя иконками, активная половина подсвечена.

**Тёмная** (основная, по макету): фото-фон как есть, стеклянные поверхности белые с низкой непрозрачностью.

**Светлая**: то же фото-фон, поверх него светлая вуаль `bg-white/70`, поверхности становятся `bg-black/5`, границы `black/10`, текст тёмный. Композиция и расположение элементов не меняются.

| Брейкпоинт | Поведение |

## 11. Иконки

Библиотека `lucide-react`, размер 20px в меню и 18px в кнопках, толщина линии 1.75.

Соответствие пунктов меню иконкам: Search → `Search`, Chat → `MessageSquare`, Agentic Chat → `Sparkles`, Studio → `Video`, Feed → `Table2`, Characters → `Users`, Stories → `BookOpen`, Personas → `Fingerprint`, Projects → `FolderOpen`.

Быстрые действия: Learn about the World → `Globe`, Generate any image → `Image`, Create AI Video → `Video`, Surprise Me → `Sparkles`.

## 12. Язык интерфейса

**Весь текст, который видит пользователь, пишется по-английски.** Это касается подписей, кнопок, плейсхолдеров, заголовков страниц, сообщений валидации и ответов сервера.

Комментарии в коде и рабочая документация остаются на русском: их читает команда, а не пользователь.

Типовые формулировки, чтобы не расходились по страницам:

| Действие | Текст |
|---|---|
| Вход | Sign in |
| Регистрация | Sign up / Create account |
| Выход | Sign out |
| Поля формы входа | Email, Password, Remember me |
| Восстановление | Forgot password? / Send reset link |
| Отправка в процессе | Signing in… / Creating account… |

## 13. Ритм отступов

Базовый шаг — **4px**, все значения кратны ему. Это обычная сетка Tailwind, никаких произвольных чисел.

| Расстояние | Значение | Где |
|---|---|---|
| Метка до поля | 8px (`mb-2`) | Формы |
| Между полями формы | 20px (`space-y-5`) | Формы |
| Заголовок блока до содержимого | 28px (`mb-7`) | Карточка входа |
| Внутренние поля карточки | 28px, на десктопе 32px (`p-7 sm:p-8`) | Карточка входа |
| Сообщение об ошибке под полем | 8px (`mt-2`) | Формы |
| Между смысловыми группами | 28–32px | Любая страница |

Правило простое: расстояние внутри группы всегда меньше, чем расстояние между группами. Если метка отстоит от своего поля дальше, чем поля друг от друга, форма читается неправильно.

---

## 14. Центрирование содержимого

Кнопки и любые элементы с содержимым по центру выравниваются через **flex**, а не через `text-align: center`.

```
flex items-center justify-center
```

Причина практическая: в React переносы строк вокруг выражения в разметке превращаются в пробельные узлы. В блочном элементе они сдвигают текст вбок, и кнопка выглядит несимметрично. Flex такие узлы игнорирует.

Это правило обязательно для всех кнопок, значков и плашек со значением по центру.

---

## 15. Выравнивание заголовков

Правило зависит от того, что за блок.

**Карточка по центру экрана** — весь текст внутри по центру: заголовок, подзаголовок, кнопка, ссылка под ней. Это замкнутый самостоятельный блок, и разнобой в нём сразу бросается в глаза.

Так оформлены: страница входа, будущие страницы подтверждения, пустые состояния, диалоговые окна.

```
<div className="mb-7 text-center">
    <h1>…</h1>
    <p>…</p>
</div>
```

**Страница со списком или лентой** — заголовок по левому краю, как и содержимое под ним. Центрировать его нельзя: он оторвётся от того, что описывает.

Так оформлены: список чатов, будущие разделы Feed, Characters, Stories, Projects.

Проверка простая: если содержимое под заголовком выровнено по левому краю, заголовок тоже слева. Если содержимое по центру, заголовок по центру.
