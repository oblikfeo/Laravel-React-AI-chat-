# Uncensia

Сервис по подписке на нейросети без цензуры.

> The universe has no restrictions. Neither should AI.

## Стек

Laravel 12 и React 19, связанные через Inertia. Оформление на Tailwind, иконки из lucide-react. База PostgreSQL на боевом сервере, SQLite для локальной разработки.

## Структура

| Папка | Что внутри |
|---|---|
| `server/` | Код приложения: Laravel и React |
| `docs/` | Журнал работы, дизайн-система, инструкция по развёртыванию |
| `figma/` | Макеты от дизайнера |
| `assets/` | Прочие материалы от заказчика |

Папка `credentials/` с доступами намеренно не хранится в репозитории.

## Просмотр фронтенда на своей машине

Бэкенд локально поднимать не нужно: интерфейс смотрится с настоящими данными боевого сервера.

```bash
cd server
npm install
npm run build
npm run preview
```

Откройте `http://localhost:3000`. Статика отдаётся из вашей папки, а запросы уходят на боевой сервер, поэтому правки вёрстки видны сразу после пересборки.

Разметку отдаёт боевой сервер, и в ней стоят имена файлов сборки с его хешами. Локальная сборка даёт другие хеши, поэтому режим просмотра подменяет имена на свои — иначе браузер загрузил бы сборку с сервера и местных правок не было бы видно.

Чтобы сборка запускалась сама при каждом изменении файла, в соседнем окне терминала запустите `npm run watch`.

На Node 20.19 и новее доступна полноценная горячая перезагрузка через `npm run dev`. На более старых версиях Vite не стартует, поэтому и сделан режим просмотра.

## Подключение модели

На боевом сервере ключ подключён, модель отвечает. Если ключ не задан, приложение возвращает нейтральное сообщение, а причина уходит в лог: внутренние подробности пользователю не показываются никогда.

Чтобы включить ответы на своей машине, получите бесплатный ключ на [openrouter.ai](https://openrouter.ai/keys) и добавьте его в `.env`:

```
OPENROUTER_API_KEY=ваш-ключ
```

Формат запросов совместим с OpenAI, поэтому так же подключаются Ollama и OpenAI — меняется только конфигурация в `config/ai.php`.
